# Tic Tac Toe

A simple two-player Tic Tac Toe game that runs in your browser. Take turns placing X and O; the game detects wins and ties and keeps a running score.

## Play

Open `index.html` in a browser, or start a local server from this directory:

```sh
python3 -m http.server 8000
```

Then visit <http://localhost:8000>.
